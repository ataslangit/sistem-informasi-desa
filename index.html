SiDesaSistem Informasi Desa

Administrasi kependudukan, layanan e-surat, dan CMS portal desa multi-tema berbasis Laravel.

Mulai Instalasi
Panduan Operator Desa

👥 Manajemen Kependudukan

Buku induk Kartu Keluarga dan penduduk berbasis NIK 16 digit, mutasi (lahir, wafat, pindah, datang), serta laporan statistik agregat.

✉️ Layanan E-Surat

Template surat otomatis, alur persetujuan berjenjang (RT → Staf → Kepala Desa), cetak PDF dengan QR Code verifikasi.

🎨 CMS Multi-Tema

Portal publik dengan tema modular (default, emerald) yang dapat diganti tanpa menyentuh kode backend maupun dashboard admin.

📊 Transparansi APBDes

Publikasi anggaran desa sesuai Permendagri 20/2018 dan pemetaan wilayah (GIS) batas desa, dusun, RW/RT, serta aset desa.

📢 PPID Desa

Layanan keterbukaan informasi publik sesuai UU 14/2008: permohonan ber-tiket, tracking, dan keberatan informasi.

🔗 Integrasi SIK

Endpoint API terautentikasi token untuk mengirim data agregat ke Sistem Informasi Kecamatan (roadmap).

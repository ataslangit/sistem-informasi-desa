# SID Versi v4.5.6

Rilis: __belum rilis__

## :rocket: Peningkatan
- Hapus duplikasi pengambilan data config pada front, hapus `data_config` dan langsung menerapkan variabel `desa`.
- Mendefinisikan semua rute secara manual di `donjo-app/config/routes.php` untuk meningkatkan keamanan dan prediktabilitas rute.

## :hammer_and_wrench: Perbaikan
- Memperbarui semua tautan yang di-hardcode dari 'surat' ke 'persuratan' di seluruh file view dan instalasi untuk konsistensi setelah penggantian nama controller.
-

## :capital_abcd: Lain-lain
- Nama tabel dan kolom database yang berkaitan dengan 'surat' (contoh: 'log_surat', 'tweb_surat_format') tidak diubah menjadi 'persuratan' untuk menjaga kompatibilitas dan menghindari perubahan yang berisiko pada skema database.
